# KILLBOX — Criterios de calidad

## Gameplay

- El jugador entiende qué debe hacer sin leer documentación extensa.
- El combate se siente responsivo.
- Las alianzas son fáciles de crear y romper.
- Las kills se sienten importantes.
- El final de partida es claro.

## Visual

- El juego debe verse bien en teléfono horizontal.
- Los personajes deben distinguirse a distancia.
- El mapa debe ser legible.
- Los efectos no deben tapar información importante.
- La estética debe sentirse propia y no como una copia directa de otro juego.

## UX

- Pocas pantallas.
- Botones grandes.
- Acciones contextuales.
- Feedback inmediato después de una kill, alianza o victoria.
- No introducir pantallas de economía durante el MVP.

## Rendimiento

- Mantener carga inicial pequeña.
- Evitar assets innecesariamente pesados.
- Objetivo de frame rate estable en teléfonos Android compatibles.
- Medir memoria y batería durante partidas largas.

## Competitivo

- El cliente no puede decidir resultados.
- Cada kill debe ser verificable.
- Cada reparto debe ser idempotente.
- El servidor debe registrar eventos importantes.
