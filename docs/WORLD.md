# KILLBOX — Mundo y mapa inicial

## Dirección artística

Mundo urbano caricaturesco con elementos de apocalipsis ligero.

No busca realismo ni gráficos AAA. La meta es una estética memorable, colorida, limpia y ligera para móviles.

## Mapa V1 — Nova City

Mapa compacto compuesto por:

- supermercado;
- restaurante;
- casas;
- apartamentos;
- parque;
- gasolinera;
- calles;
- callejones;
- vehículos abandonados;
- barricadas.

## Diseño del mapa

El mapa debe tener:

- rutas principales;
- rutas secundarias;
- zonas abiertas;
- zonas de cobertura;
- puntos de riesgo;
- lugares para emboscadas;
- suficientes rutas de escape.

No debe existir un escondite absolutamente seguro.

## Cámara

Vista superior 2D/2.5D con profundidad visual ligera.

El jugador debe poder identificar personajes, obstáculos, objetos y efectos rápidamente.

## Arte

Prioridades:

1. Siluetas claras.
2. Lectura inmediata del gameplay.
3. Animaciones expresivas.
4. Efectos atractivos pero ligeros.
5. Pocos elementos que saturen la pantalla.

## Futuro

Después de validar Nova City se pueden añadir mapas temáticos, por ejemplo:

- zona industrial;
- estación central;
- centro comercial;
- barrio abandonado;
- zona costera.
