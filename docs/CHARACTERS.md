# KILLBOX — Personajes y roles

## Principio

Los roles describen profesiones/identidades y modifican el estilo de juego. Ningún rol es pacifista: todos pueden combatir y eliminar.

## Roster inicial conceptual

### Rex — Mecánico

Habilidad: Barricada.

Coloca una barrera temporal para bloquear rutas, escapar o preparar una emboscada.

### Luna — Detective

Habilidad: Rastro.

Detecta señales recientes de actividad de otros jugadores durante un tiempo limitado.

### Max — Explosivista

Habilidad: Trampa.

Coloca una trampa visible con suficiente lectura visual para que exista contra-juego.

### Maya — Médica

Habilidad: Primeros auxilios.

Recupera una cantidad limitada de vida con enfriamiento.

### Kai — Mensajero

Habilidad: Turbo.

Obtiene velocidad temporal para escapar o perseguir.

## Reglas de diseño de personajes

- Siluetas reconocibles a primera vista.
- Profesiones visibles en vestimenta y accesorios.
- Animaciones cortas y expresivas.
- Cada habilidad debe entenderse sin leer un manual.
- Ningún personaje debe ser claramente superior en todas las situaciones.
- El roster inicial debe poder ampliarse sin romper el balance.

## Pendiente antes de producción

- Nombre definitivo.
- Estadísticas base.
- Cooldowns.
- Animaciones.
- Efectos visuales.
